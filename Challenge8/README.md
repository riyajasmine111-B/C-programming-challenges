It uses a 2D array to analyse risk scores in a grid and identify important patterns.

Key Features:
- Calculates row and column totals and identifies the highest ones.
- Finds the maximum score and all its positions.
- Counts scores that meet or exceed the given threshold.
- Calculates main and secondary diagonal sums.
- Finds the total of boundary cells.
- Identifies local hotspots in the grid.
- Displays the final risk status as CRITICAL, WARNING, or NORMAL.
Concepts Used: C programming, 2D arrays, nested loops, conditional statements, and input validation.
