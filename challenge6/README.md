Algorithm
1. Start.
2. Read N and check that it is between 5 and 12. Enter N readings between 0 and 1000.
3. Display the original array.
4. Calculate the sum, average, minimum and maximum.
5. Find the second-largest distinct value.
6. Count the local peaks in the array.
7. Find the longest increasing continuous sequence.
8. Read K and rotate the array right or left as required.
9. Read R, calculate D = (R % 9) + 1, and count the elements divisible by D in the rotated array.
10. Stop.
